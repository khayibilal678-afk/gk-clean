# Planning Ménage — جدول التنظيف

موقع بالفرنسية والعربية لتوزيع المنازل على العمال، وحساب ساعات العمل، وإصدار الفواتير.
الملف الأساسي هو `index.html`، ويعمل بدون إنترنت.

## التجربة على حاسوبك الآن (بدون إنترنت)

1. ضع الملف `index.html` في أي مجلد على حاسوبك.
2. انقر عليه مرتين ليفتح في Chrome أو Edge (يفضَّل أيضًا Firefox).
3. أنشئ اسم المستخدم وكلمة المرور، ثم ابدأ بإضافة المنازل والعمال.

بدون إنترنت يعمل كل شيء. الفرق الوحيد أن الخط يتحول إلى خط النظام (Segoe UI)، فيبدو الشكل أبسط قليلًا.
احتفظ بالملف في مكان ثابت. إذا نقلته إلى مجلد آخر فقد لا يجد المتصفح بياناتك، وفي هذه الحالة استعمل النسخة الاحتياطية.

## ما الجديد

- **الخدمات:** لكل منزل خدمة رئيسية (تنظيف المنزل، تنظيف الزجاج، الكي، المطبخ والفرن، نهاية الإيجار، بعد الأشغال، السجاد، الحديقة، المكاتب، الأجزاء المشتركة، التعقيم). يمكنك إعادة تسميتها وإضافة خدمات جديدة وحذفها من الإعدادات. ولكل منزل أن يحمل وقتًا مختلفًا لكل خدمة (مثلًا الزجاج 45 دقيقة)، ويُقترح عند اختيار الخدمة في المهمة.
- **Excel:** في تبويب الساعات زر «Excel» لتصدير ملف `.xlsx` فيه: ملخص الساعات، وورقة «حسب الخدمة»، وورقة **لكل عامل** (المنازل التي عمل فيها، الخدمة، الوقت الأساسي، الإضافي، المجموع، مع ملخص حسب المنزل وحسب الخدمة)، وورقة بكل المهام. المجاميع صيغ Excel حية تتغير إن عدّلت الأرقام. في الإعدادات زر «تصدير كل شيء إلى Excel» (المهام والمنازل والعمال).
- **الطباعة:** زر «طباعة» في الجدول وفي الساعات. اختر «حفظ بصيغة PDF» من نافذة الطباعة إن أردت ملف PDF.
- **الفواتير:** في تبويب المنازل زر «فاتورة» لكل منزل. اختر الفترة والمهام المشمولة والسعر بالساعة، ثم اطبع أو نزّل الفاتورة بصيغة PDF (عبر الطباعة) أو HTML أو Excel.
- **بيانات مؤسستك:** من الإعدادات أدخل اسم المؤسسة والعنوان ورقم الضريبة وIBAN والسعر الافتراضي بالساعة ونسبة الضريبة، وتظهر على كل فاتورة.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا (New repository) على github.com، مثلًا باسم `planning-menage`.
2. اضغط **Add file → Upload files**، واسحب الملفين `index.html` و`sw.js` (والملف `README.md` إن أردت)، ثم **Commit changes**.
3. افتح **Settings → Pages**، واختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/planning-menage/`

الملف `sw.js` يحفظ نسخة من الموقع في المتصفح بعد أول زيارة، فيفتح بدون إنترنت.
على الخطة المجانية يجب عادةً أن يكون المستودع عامًا.

## ملاحظات مهمة

- **البيانات تُحفظ في متصفح كل جهاز** ولا تنتقل بين الأجهزة. استخدم «تنزيل نسخة احتياطية» بانتظام، و«استعادة نسخة احتياطية» لنقلها.
- **تسجيل الدخول حاجز بسيط وليس حماية قوية.** الموقع ثابت بلا خادم، وشيفرته مرئية لمن يفتح الصفحة.
- **نسبة الضريبة الافتراضية 21%.** راجعها مع محاسبك وعدّلها من الإعدادات قبل إصدار أي فاتورة.
- رقم الفاتورة يزداد تلقائيًا (مثل `2026-001`) عند الطباعة أو التنزيل. يمكنك تعديل الرقم يدويًا قبل ذلك.
- الفاتورة تُحسب بالدقيقة وتُقرَّب لكل سطر إلى السنت، فلا يوجد فرق بين مجموع السطور والإجمالي.
